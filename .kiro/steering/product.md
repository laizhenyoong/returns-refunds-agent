# Product Overview

This project is a **Returns & Refunds assistant** — an AI agent that helps customers
handle product returns and refund requests.

## Purpose

Demonstrate how to build a focused, production-shaped agent using the
**Strands Agents SDK** and deploy/operate it with the **Amazon Bedrock AgentCore CLI**.

## Guiding Principles

- **Educational first**: The codebase is a learning artifact. Favor clarity over
  cleverness so a reader can follow how the agent is assembled.
- **Minimal and focused**: Implement only what is needed to demonstrate the core
  Returns & Refunds concepts. Avoid speculative features, extra abstractions, and
  defensive code beyond what the task requires.
- **Core concepts over completeness**: When a choice exists between a broad, generic
  solution and a small example that clearly illustrates the concept, choose the small
  example.

## Scope

- Handle return eligibility checks, refund initiation, and status lookups as the
  primary agent capabilities.
- Keep tool implementations small and self-contained so each demonstrates one concept.
